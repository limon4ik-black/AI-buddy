# AI-buddy: прототип интерфейса

Адаптивный интерфейс (компьютер и телефон): вход, главная, чат с AI-buddy, заметки с доской, чек-лист с календарём, профиль.
Данные синтетические, ответы AI-buddy имитируются (`src/js/services/assistant.js`).

## Запуск
Сборка не нужна. Откройте `index.html` в браузере двойным кликом или через расширение Live Server в VS Code.

## Вход
Нажмите «Войти как демо-стажёр» либо введите любую почту вида name@company.test и пароль от 4 символов.

## Структура
- `src/css/`: токены цветов, базовые стили, каркас, экраны, адаптив
- `src/js/data/`: тестовые данные
- `src/js/services/`: имитации сервисов (ответы AI-buddy, заявка на отгул)
- `src/js/components/`, `src/js/screens/`: отрисовка интерфейса
- `docs/specs/`: SDD-спецификации (заполнить)
- `tests/`: автотесты (заполнить)
- `mock/`: имитации интеграций (заполнить)
