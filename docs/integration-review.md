## Интерфейс

Оформление и навигация перенесены из `ai-buddy.zip` в существующий React-фронт. Главная, календарь, чек-лист, профиль и питомец используют настоящие данные. Сохранены почтовый код входа, регистрация, восстановление пароля, Google OAuth при наличии настроек, история чата, источники, заявки, заметки и доски Excalidraw. Моковые пользовательские данные и имитация ответов из архива не перенесены. Подача отпуска не добавлялась: соответствующего API нет.

Календарь показывает начало стажировки и фактические даты выполнения шагов. API не содержит дедлайнов, поэтому интерфейс не выдумывает просроченные задачи.

## Исправления ревью

- Метрики освобождают in-flight при панике, учитывают восстановленный HTTP 500 и первый окончательный статус; обёртка поддерживает WebSocket.
- `make rag` подключает мониторинг, как и `make up`; настройки лимитера передаются в Note из окружения.
- Длина истории RAG согласована с допустимой длиной ответа Chat.
- Разрешения Note применяются к bundled JSON-документам; они зарегистрированы в каталоге Note для открытия источников.
- В Chat/RAG сохранены локальные исправления JSON-планировщика и обработки ошибок провайдера 429/503.
- Перегрузка Groq (503) получает один ограниченный повтор; постоянная ошибка показывается как временная недоступность AI, без неверного утверждения о VPN.
- Исправлены гонки переключения чата и автосохранения доски; внешние ссылки ограничены HTTP/HTTPS.
- Независимые фронт, RAG, мониторинг и отчёты исключены из Docker-контекста Go-сервисов, чтобы их изменения не вызывали лишнюю пересборку Go.

## Ограничения

Живой RAG требует действующего ключа Groq, доступного соединения и свободной квоты. При настроенном `RAG_HTTPS_PROXY` должен работать соответствующий прокси/VPN. Локальный healthcheck не подтверждает доступность внешнего провайдера.

Фронт использует REST для чата. Существующий WebSocket поддерживает Bearer-заголовок; авторизация нативного браузерного WebSocket отдельно не реализована.

Лимитер Auth пока использует адрес gateway, поэтому несколько клиентов делят одну квоту. Это существующее ограничение, а не индивидуальная квота пользователя.

## Запуск

Из этой рабочей копии: `make rag` — настоящий RAG, `make up` — мок RAG. Сайт: `http://localhost:8080`; локальная почта: `http://localhost:8025`; Grafana: `http://localhost:3000`; Prometheus: `http://localhost:9090`. Остановка: `make down`; пользовательские тома БД сохраняются.

Google OAuth и корпоративная выдача доступов требуют отдельной настройки/интеграции; corpmock остаётся демонстрационным.
