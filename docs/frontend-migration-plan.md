# Перенос интерфейса ai-buddy

Обновлено 16 ноября 2026 после ребейза на `883cd98` и завершения переноса экранов.

## Реализация

Рабочее приложение остаётся в `frontend` на React/TypeScript/Vite. `ai-buddy` используется как эталон оформления и компоновки; его синтетические данные и имитации сервисов не подключаются.

- Главная: настоящий профиль, прогресс адаптации, календарь фактических событий, быстрые вопросы, последние заметки и бобрик.
- Чат: отдельный список разговоров и переписка, поиск, создание, переименование и удаление; мобильный переход между списком и перепиской. Сохранены RAG, история, источники, подтверждение запросов доступа и повтор ответа.
- Заметки: список карточек с поиском и редактор рядом; на телефоне отдельные состояния списка/редактора. Первая строка содержимого используется как заголовок без изменения серверного формата. Сохранение явное, с отображением несохранённых изменений; при ошибке или конфликте версий черновик остаётся в редакторе. Переход с главной открывает выбранную заметку.
- Доски: доступны из заметок, сохранены Excalidraw, существующие сцены, вложения и автосохранение.
- Чек-лист: отдельный экран с фильтрами, статусами, инструкциями, прогрессом и календарём. Дублирующий старый список из профиля удалён.
- Профиль: карточка сотрудника, команда, прогресс, бобрик, контакты, заявки, изменение профиля/пароля и выход.
- Навигация: пять основных разделов; на телефоне нижняя панель. Справочники команд, сервисов и знаний сохранены.
- Вход: зелёная панель с возможностями и форма в стиле прототипа. Регистрация удалена из формы и `useBuddy.login`; клиент вызывает только `/auth/login`. Кнопка Google также удалена, поскольку существующий OAuth может создавать неизвестного пользователя. Вход по коду и восстановление пароля сохранены. Новых пользователей добавляет администратор в БД. Серверные маршруты авторизации не изменены.

## Границы API

Календарь использует дату начала и даты выполнения шагов: сервер не содержит дедлайнов. Создание личных задач, отгулы, переписки сотрудников и серверные метаданные заметок (закрепление, отдельные заголовки и цвета) требуют отдельных API и не заменяются фиктивным успешным ответом. Цвета карточек — оформление. Старые заметки и сцены не конвертируются в несовместимый формат прототипа.

## Запуск сервисов

В рамках переноса не менялись Makefile, Dockerfile, Compose, nginx, package.json/lockfile и настройки сервисов. Сохраняются build context `frontend`, результат `dist`, same-origin маршруты `/api/`, `/notes-api/`, `/board-api/`, CSP, порты, сети, тома, миграции и зависимости запуска. Node на хосте для штатного Docker-запуска не требуется. Тома и `.env` не удалялись.

Ранее выявленное ограничение полного `make up` описано в `startup-rebase-check.md`: Docker-сборка Go останавливалась на DNS `proxy.golang.org`. Эта проблема не устранялась изменениями UI. Успешная сборка фронта не является подтверждением поднятия всех сервисов.

## Проверки

- Production build (`tsc -b && vite build`) — успешно.
- 29 frontend-тестов — успешно; покрытие строк 88,07%, statements 86,57%, пороги 81% сохранены.
- В тестах проверены отсутствие регистрации/Google и запросов `/auth/register`, ошибочный пароль, OTP и восстановление пароля, чат и источники, запросы доступа, чек-лист, редактирование профиля, CRUD заметок/досок, поиск заметок и сохранность черновика при конфликте версий.
- Chromium с тестовыми API: вход, главная, чат, заметки, профиль и чек-лист; ширины 360, 390, 768 и 1440 px для основных сценариев. Проверены мобильные переходы, отсутствие ошибок JavaScript и горизонтального переполнения. Это проверка UI с тестовыми ответами, а не живой интеграции с бэкендом.
