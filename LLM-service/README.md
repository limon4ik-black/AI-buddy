# AI Buddy

FastAPI → Qwen/Qwen3-Embedding-0.6B (CUDA, FP16) → PostgreSQL/pgvector → Groq API.
Использует существующие таблицы `documents` и `chunks`, ничего не переиндексирует.
Запросы кодируются с Qwen `query` prompt; поиск — cosine distance, 1024 измерения.
Для уточняющих вопросов к поисковому запросу добавляются последние 3 сообщения пользователя.
В Groq передаются история диалога и найденные фрагменты с названиями источников.

Генерация: `GROQ_API_KEY` и `GROQ_MODEL` в `.env` (по умолчанию `qwen/qwen3.8-27b`).

## Запуск

Из каталога `LLM-service`:

```bash
uv sync
# Заполнить .env по образцу dotenv, включая FRIEND_TOKEN.
# Если существующая БД остановлена:
docker compose up -d postgres
uv run uvicorn src.main:app --host 127.0.0.1 --port 8000
```

Требуются Python 3.14+, NVIDIA GPU с доступной CUDA и доступ к Hugging Face
при первом скачивании модели. При отсутствии CUDA сервис завершает запуск с ошибкой.
На старте проверяются модель и размерность эмбеддингов в БД.
Запускать один worker: каждый worker загружает отдельную копию модели в GPU.
Не запускайте второй экземпляр и не используйте `--reload`: это увеличивает
пиковое потребление RAM. Файл `.model.lock` защищает от запуска второй копии
до загрузки PyTorch и весов; после завершения процесса блокировка снимается автоматически.
Скачанные веса хранятся на диске, но при каждом запуске снова загружаются в память.
Схему `postgresql/schema.sql` на заполненной БД повторно применять не нужно.

## API

`POST /chat`, заголовок `Authorization: Bearer <значение FRIEND_TOKEN из .env>`.
`friend` — назначение токена; сам секрет берётся из `FRIEND_TOKEN`.

```json
{
  "message": "Как устроен процесс разработки?",
  "history": [
    {"role": "user", "content": "Расскажи про Авито"},
    {"role": "assistant", "content": "Авито — это..."}
  ]
}
```

Ответ: `{"answer": "Текст ответа [1]", "sources": [...]}`.
Каждый источник содержит `id`, `source`, `headings`, `score` (cosine similarity).
Нумерация источников соответствует ссылкам `[1]`, `[2]` в контексте модели.
История необязательна, максимум 20 сообщений; сообщение — до 8000 символов.
Ошибки: 401 — авторизация, 422 — формат запроса, 502 — ошибка БД/эмбеддинга/Groq.
Swagger: `/docs` (это документация; единственная бизнес-ручка — `/chat`).

```bash
uv run pytest
```

Тесты API используют подмену RAG и не обращаются к Groq, GPU или БД.
